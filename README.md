# life-sim-game-builder

一个 **ZCode skill**：批量生产"单文件人生模拟游戏"——零依赖、离线可玩、双击即开的 HTML 网页游戏。

同一台引擎，任意题材：恋爱修罗场、宫斗、武侠客栈、修仙、经营小店、末世生存……机制内核固定（时间刻度 × 现金流 × 关系阶段机 × 剧情事件引擎 × 手机社交 × 离线存档），题材/剧情/美术全由共创产出。

![demo home](docs/screenshots/demo-home.png)

## 它生产什么

每个产物都是一个 `.html` 文件：

- **单文件、零外部请求**：无 CDN、无图片资源（视觉 = CSS 渐变 + emoji），断网双击可玩；
- **完整机制**（源自对一类中文人生模拟游戏的逆向抽象）：
  - 时间刻度：每天 4 时段（晨/午/暮/夜），日结/月结双钩子，事件阻断时间、快进只丢可再生内容；
  - 现金流账本：所有收支走统一账本（余额不足自动回滚），工资岗 + 3 阶段报价交付的接单线；
  - 关系阶段机：`未相识→相识→朋友→恋人/秘密关系→前任/订婚→结婚`，好感正加成全局减半、偏好匹配、里程碑心声、生气/冷却/冷淡裂缝；
  - 剧情引擎：`场景 → 选项 → 效果(fx DSL)`，技能判定（dc vs 技能值），21 个标准 fx 键；
  - 手机社交：自由聊天（关键词意图识别 + 每人专属声线）、心跳话题（3 天冷却）、动态流点赞/回应；
  - 存档：localStorage 自动保存 + 四级瘦身 + 历史副本 + 导出/导入 JSON + schema 迁移；
  - 成就 / 结局收集、年龄分级门与虚构声明、全局错误兜底面板。
- **生产线的四大纪律**：
  1. 剧情共创：用户给方向 → 头脑风暴式逐问；不给方向 → grill-me 式轮次追问（每题带推荐答案）；产出《游戏设计圣经》并经用户确认才动工；
  2. 引擎与内容分离：题材工作 = 填 THEME SLOT 数据，不为题材魔改引擎主干；
  3. 三重深度 QA（见下）；
  4. 平台反擦除：成品不含任何平台特化物（客服话术/售卖话术/防盗声明/缓存参数）。

## 快速开始

**试玩引擎自带演示题材**（北岸日记）：直接双击 `assets/engine-skeleton.html`。

**安装 skill**：把本仓库放入 ZCode 可发现的位置，例如：

```bash
# 用户级（推荐，所有项目可用）
git clone https://github.com/Chi-9966/life-sim-game-builder.git ~/.agents/skills/life-sim-game-builder

# 或项目级
git clone https://github.com/Chi-9966/life-sim-game-builder.git <你的项目>/.agents/skills/life-sim-game-builder
```

然后在 ZCode 里直接说：

- 「帮我做一个武侠客栈风格的经营养成小游戏」（有方向 → 头脑风暴共创）
- 「再做一个人生模拟游戏，随你发挥」（无方向 → 轮次追问选型）
- 「批量做三个不同题材的小游戏」（先给排期表，逐个走完全流程）

## QA：三重深度检查

1. **A · 第一性原理审计**（12 条）：核心幻想 10 分钟可达、循环闭合、经济学自洽（月支出/首月收入 1.2–3 倍带宽）、关系经济（好感路径天数表）、事件频道覆盖、无白给结局……
2. **B · 功能完备度**：`qa_lint.mjs` 机械检查（语法/handler 闭合/场景引用闭合/fx 词表闭合/角色地点交叉引用/存档体系）+ 十条点击流 + 状态边界；
3. **C · 多设备 UI**：320/375/414/768/1440 视口矩阵截图、刘海安全区、长名/大数/长文极值、键盘弹起、色弱可辨。

自检命令：

```bash
node scripts/qa_lint.mjs assets/engine-skeleton.html --demo   # 骨架基线
node scripts/smoke_driver.cjs                                  # 无头浏览器 12 步冒烟
```

当前骨架验证状态：lint PASS；运行时 harness（创建/时钟/饥饿链/聊天/接单/存档往返）PASS；无头 Chrome 12 步冒烟全 PASS、0 console 错误。
